# JAMIL AI Mobile (Expo)

حزمة Android أولية مستقلة تستخدم مشروع Supabase نفسه. تدعم حاليًا إرسال رمز بريد إلكتروني والتحقق منه، وقراءة رصيد المحفظة والخدمات المفعّلة والمشاريع الخاصة بالمستخدم وفق RLS. لا تحتوي مفاتيح مزودي الذكاء الاصطناعي ولا بيانات توضيحية ثابتة.

## التشغيل

```bash
cd apps/mobile
npm install
cp .env.example .env
# ضع عنوان Supabase ومفتاح anon/public في .env
npm start
```

المتغيران المطلوبان هما `EXPO_PUBLIC_SUPABASE_URL` و`EXPO_PUBLIC_SUPABASE_ANON_KEY`. لا تضع `service_role` أو مفاتيح المزودين في تطبيق الهاتف. يجب تهيئة إعدادات الروابط العميقة وقوالب OTP في Supabase عند الحاجة.

هذه نسخة تأسيسية وليست مكافئة بعد لكل ميزات الويب؛ لم يُبنَ APK/AAB ولم تُختبر على جهاز فعلي. الدفع ورفع الإيصالات والمحادثة والتوليد والإشعارات ما زالت بحاجة إلى تنفيذ وربط واختبار قبل الادعاء بتكافؤ الميزات.
